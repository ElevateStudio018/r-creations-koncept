Grundare

Hej, jag heter Rakesh.

Med ett skarpt öga för estetik, teknisk skicklighet och ett kreativt förhållningssätt skapar vi visuellt fängslande event som lämnar ett bestående intryck på gästerna.

Oavsett om det är ett bröllop, ett företagsevent eller ett annat särskilt firande arbetar vi nära våra kunder för att förstå deras vision — och levererar minnen som kan återupplevas genom bilder och film.
